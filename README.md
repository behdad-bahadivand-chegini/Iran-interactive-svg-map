# نقشه تعاملی ایران - اطلاعات استان‌ها و پروژه‌ها

این پروژه یک نقشه تعاملی از ایران است که با استفاده از SVG و JavaScript ساخته شده است. با کلیک روی هر استان، اطلاعات پروژه‌های مرتبط با آن استان در یک پاپ‌آپ نمایش داده می‌شود. این ابزار می‌تواند برای نمایش پروژه‌های عمرانی، گردشگری، یا هر نوع داده‌های مکانی دیگر مورد استفاده قرار گیرد.

## ویژگی‌ها

- 🌍 نقشه برداری کامل از استان‌های ایران (۳۱ استان + جزایر و پهنه‌های آبی)
- 🖱️ کلیک روی هر استان برای نمایش پروژه‌های مرتبط
- 💬 پاپ‌آپ زیبا با اطلاعات پروژه شامل نام، مکان، تاریخ و لینک خبر
- 🎨 ظاهر مدرن با رنگ‌بندی جذاب و افکت‌های CSS
- 📱 کاملاً ریسپانسیو (مناسب برای موبایل و تبلت)
- 🔍 قابلیت نمایش نام استان‌ها با هاور موس (عنوان شناور)
- 🗂️ داده‌های پروژه به صورت متمرکز در JavaScript قابل ویرایش



- **HTML5**: ساختار اصلی صفحه
- **CSS3**: طراحی ظاهری، انیمیشن‌ها و ریسپانسیو
- **JavaScript (Vanilla)**: منطق تعامل با نقشه و مدیریت پاپ‌آپ
- **SVG**: فرمت برداری نقشه ایران (مسیرهای استان‌ها)

## نحوه استفاده

1. فایل `index.html` (یا هر نام دیگری که دارد) را در مرورگر خود باز کنید.
2. نشانگر موس را روی هر استان ببرید تا نام آن نمایش داده شود.
3. روی استان مورد نظر کلیک کنید تا پنجره اطلاعات باز شود.
4. در پنجره باز شده، لیست پروژه‌های آن استان (در صورت وجود) نمایش داده می‌شود.
5. اگر پروژه‌ای لینک خبر داشته باشد، می‌توانید با کلیک روی دکمه «مشاهده خبر» به صفحه مربوطه بروید.

## ساختار داده‌ها

داده‌های پروژه‌ها در فایل HTML در بخش `<script>` به صورت آبجکت `provinceData` ذخیره شده است. هر استان یک کلید با نام خود دارد و مقدار آن شامل آرایه‌ای از پروژه‌هاست. هر پروژه شامل فیلدهای زیر است:

```javascript
{
  id: 1,
  name: "نام پروژه",
  location: "موقعیت مکانی",
  date: "تاریخ شروع - پایان",
  link: "https://example.com/news"  // اختیاری
}
```

### مثال

```javascript
"تهران": {
  projects: [
    {
      id: 3,
      name: "شهرداری منطقه 7",
      location: "شهر تهران، منطقه ۲ و ۵",
      date: "۱۴۰۰/۰۱/۱۵ - ۱۴۰۲/۱۲/۳۰",
      link: "https://example.com/news3"
    },
    // ...
  ]
}
```

## شخصی‌سازی

- **افزودن استان جدید**: مسیر SVG استان را به `<g>` مربوطه اضافه کنید و یک متن با کلاس `province-text` درون آن قرار دهید.
- **تغییر رنگ‌ها**: کلاس‌های `path-city-g1` تا `path-city-g4` برای رنگ‌بندی استان‌ها استفاده شده‌اند.
- **ویرایش داده‌ها**: آبجکت `provinceData` را مطابق نیاز تغییر دهید.
- **اضافه کردن پروژه**: پروژه جدید را به آرایه `projects` استان مربوطه اضافه کنید.

## ساختار فایل

```
index.html
├── SVG map of Iran (paths for each province)
├── CSS styles (embedded)
└── JavaScript (embedded)
    ├── provinceData object
    ├── showPopup, closePopup functions
    └── Event listeners for clicks
```
