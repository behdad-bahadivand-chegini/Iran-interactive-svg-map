# نقشه تعاملی ایران – نمایش اطلاعات استان‌ها و پروژه‌ها

این پروژه یک نقشه تعاملی از ایران است که با استفاده از SVG و JavaScript ساخته شده است. با کلیک روی هر استان، اطلاعات پروژه‌های مرتبط با آن استان در یک پاپ‌آپ نمایش داده می‌شود. مناسب برای نمایش پروژه‌های عمرانی، گردشگری، یا هر نوع داده‌های مکانی دیگر.

## ✨ ویژگی‌ها

- 🌍 نقشه کامل ۳۱ استان ایران به همراه جزایر و پهنه‌های آبی
- 🖱️ کلیک روی هر استان برای نمایش پروژه‌های مرتبط
- 💬 پاپ‌آپ زیبا با اطلاعات پروژه شامل نام، مکان، تاریخ و لینک خبر
- 🎨 ظاهر مدرن با رنگ‌بندی جذاب و افکت‌های CSS
- 📱 کاملاً ریسپانسیو (مناسب برای موبایل و تبلت)
- 🔍 نمایش نام استان‌ها با هاور موس (عنوان شناور)
- 🗂️ داده‌های پروژه به صورت متمرکز در فایل JavaScript قابل ویرایش
- 🧩 ساختار ماژولار (HTML, CSS, JavaScript جدا)

## 🚀 تکنولوژی‌های استفاده شده

- **HTML5**: ساختار اصلی صفحه
- **CSS3**: طراحی ظاهری، انیمیشن‌ها و ریسپانسیو
- **JavaScript (Vanilla)**: منطق تعامل با نقشه و مدیریت پاپ‌آپ
- **SVG**: فرمت برداری نقشه ایران (مسیرهای استان‌ها)

## 📁 ساختار فایل‌ها

پس از تغییر به ساختار ماژولار، پروژه به شکل زیر سازماندهی شده است:

```
iran-interactive-map/
├── index.html          # صفحه اصلی (فقط HTML و ارجاع به فایل‌های خارجی)
├── style.css           # تمام استایل‌های پروژه
├── script.js           # منطق تعامل، داده‌های استان‌ها و رویدادها
├── README.md           # مستندات پروژه
└── screenshot.png      # تصویر پیش‌نمایش (اختیاری)
```

### فایل‌ها به طور خلاصه

- **index.html**: شامل ساختار اصلی، تگ‌های `<link>` و `<script>` برای فراخوانی فایل‌های CSS و JS.
- **style.css**: تمام ظاهر و افکت‌های بصری.
- **script.js**: شامل آبجکت `provinceData`، توابع نمایش/بستن پاپ‌آپ، و رویدادهای کلیک روی استان‌ها.

## 💻 نحوه استفاده

1. مخزن را کلون کنید یا فایل‌ها را دانلود کنید.
2. فایل `index.html` را در مرورگر خود باز کنید.
3. نشانگر موس را روی هر استان ببرید تا نام آن نمایش داده شود.
4. روی استان مورد نظر کلیک کنید تا پنجره اطلاعات باز شود.
5. در پنجره باز شده، لیست پروژه‌های آن استان (در صورت وجود) نمایش داده می‌شود.
6. اگر پروژه‌ای لینک خبر داشته باشد، می‌توانید با کلیک روی دکمه **مشاهده خبر** به صفحه مربوطه بروید.

## 🗃️ ساختار داده‌ها

داده‌های پروژه‌ها در فایل `script.js` درون آبجکت `provinceData` ذخیره شده است. هر استان یک کلید با نام خود دارد و مقدار آن شامل آرایه‌ای از پروژه‌هاست.

```javascript
const provinceData = {
  "تهران": {
    projects: [
      {
        id: 1,
        name: "نام پروژه",
        location: "موقعیت مکانی",
        date: "۱۴۰۰/۰۱/۰۱ - ۱۴۰۲/۱۲/۲۹",
        link: "https://example.com/news"
      },
      // ...
    ]
  },
  // ...
};
```

- **id**: شناسه یکتا (اختیاری)
- **name**: نام پروژه
- **location**: موقعیت جغرافیایی پروژه
- **date**: تاریخ شروع و پایان (یا هر بازه زمانی دیگر)
- **link**: آدرس اینترنتی خبر یا صفحه مرتبط (اختیاری)

## 🛠️ شخصی‌سازی

### افزودن استان جدید
1. مسیر SVG استان را در فایل `index.html` به یک عنصر `<g>` با یک `<path>` و `<text>` اضافه کنید (مشابه سایر استان‌ها).
2. داده‌های مربوط به استان را در `provinceData` در `script.js` وارد کنید.

### تغییر رنگ‌بندی استان‌ها
کلاس‌های `path-city-g1` تا `path-city-g4` در `style.css` رنگ استان‌ها را مشخص می‌کنند. می‌توانید این رنگ‌ها را تغییر دهید.

### ویرایش داده‌ها
آبجکت `provinceData` را در `script.js` مطابق نیاز تغییر دهید.
